# Thực hành Git và GitHub

Tác giả: Nguyễn Văn Chương

## Mục tiêu
Quản lý phiên bản mã nguồn bằng Git và GitHub.

## Nội dung đã thực hành
- Tạo kho Git.
- Lưu thay đổi bằng add và commit.
- Xem lịch sử bằng log và so sánh bằng diff.
- Khôi phục tệp bằng restore.
- Tạo nhánh và gộp nhánh.
- Đưa mã nguồn lên GitHub bằng push.
